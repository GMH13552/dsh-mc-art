# 两个 skill 里**允许出现**的记号（白名单）。判据是倒过来的：不在这里的就要红。
#
# 为什么倒过来：以前是"已知私有词"黑名单，它只能抓到**已经发现过**的泄漏。
# 实测漏出去的那些（作者的模组资产名、第三方模组缩写）没一个在黑名单上 —— 新项目的
# 新名词永远会漏。改成白名单之后，**新名词默认失败**，而加一条白名单是一次显式决定
# （"这是原版/API/格式词"），正是这个泄漏需要的审查动作。
# （这里**故意不把那些词抄一遍**：这份白名单是跟踪文件，抄一遍等于又贴到公开仓库上。）
#
# 约定：示例一律写成占位符（`examplemod` / `example_*` / `ModelExample*` / `<...>`），
# 不由白名单管 —— 它们自带 `example` 前缀，门禁直接放行。
#
# 一行一个。`#` 后面写理由。理由分四类：
#   vanilla  = 原版 Minecraft 的资产/类/字段名
#   api      = Minecraft/Forge/NeoForge/Java 的 API 名
#   format   = 文件格式、JSON 字段、目录名、命令行开关
#   engine   = mc-art 引擎自己的 CLI/API/字段名（它随包发，公开代码）
#   tool     = 本仓库的工具/脚本名
